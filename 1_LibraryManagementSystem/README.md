# Library Management System

A simple Library Management System built with Core Java to demonstrate Object-Oriented Programming concepts.

## Features

- Add new books
- Remove books by ISBN
- Search books by title
- Search books by author
- Borrow books
- Return books
- Display available books
- Display all books with statistics

## Technologies Used

- Java (Core Java)
- Object-Oriented Programming (OOP)
